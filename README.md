### Projects

**[trading-system](https://github.com/harrywinter06-code/trading-system)** — Autonomous daily trading pipeline. Separate research agents pull arXiv papers and market sentiment to feed the next generation of strategies.

**[internship-hunter](https://github.com/harrywinter06-code/internship-hunter)** — Automated internship application pipeline. Discovers roles from Remotive, Greenhouse/Lever ATS boards, Reed.co.uk, and funding news feeds; generates tailored cover letters and cold emails using Claude Sonnet with prompt caching; manages an email queue with Hunter.io address lookup and Gmail delivery through a Streamlit dashboard.
